# AI Defense Project

Assessment tools to help individuals and businesses understand their AI readiness.

## Structure

- **`/business`** — SVI Business Assessment (Express + React, static frontend + Node API)
- **`/personal`** — Personal Career AI-Readiness Assessment (Next.js 15 + TypeScript)
